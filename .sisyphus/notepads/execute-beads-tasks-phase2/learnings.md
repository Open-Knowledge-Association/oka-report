# Learning Notes - Phase 2

## Project Structure
- Frontend: apps/web (TanStack Start + shadcn/ui)
- API: apps/api (Hono)
- Database: packages/db (Prisma)
- Utils: packages/utils (Wikimedia client)

- Using bun as package manager and runtime

- Using shadcn/ui components
